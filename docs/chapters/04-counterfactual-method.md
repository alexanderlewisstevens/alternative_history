# Counterfactual Method

Counterfactual history asks what might have happened if something had gone differently. Used badly, it becomes a game of imaginary empires and swapped winners. Used well, it exposes contingency.

## A Good Counterfactual

- Starts from a clearly defined point of divergence.
- Respects the material constraints of the period.
- Names the forces that would resist the imagined change.
- Avoids making later outcomes feel inevitable.
- Returns to the real historical record with a sharper question.

## Example Questions

- What had to be true for an empire to survive?
- What alternatives did historical actors believe were available to them?
- Which outcomes later became naturalized as inevitable?
- Which lost possibilities still shape political imagination?

## Boundary

This book can include speculative narratives, but they should be labeled as speculative. The reader should always know when the text has moved from source-based history into historical imagination.
