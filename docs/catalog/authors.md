# Thinkers

This index tracks writers whose work can organize a serious reading path in theory, criticism, historiography, or historical imagination.

The goal is not to include every important author. The goal is to identify thinkers whose texts help the project ask better questions about interpretation, memory, power, evidence, translation, narration, and historical judgment.
