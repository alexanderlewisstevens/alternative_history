# Bibliography

This page will become the master bibliography for the book. Keep it practical, edition-aware, and source-forward.

The bibliography tracks texts we intend to read, cite, summarize, or excerpt. It should not become a dump of search results, repository links, or unsorted open-access material.

## Format

Use a readable citation followed by a link and rights note:

> Author. *Title*. Translator or editor if relevant. Publisher or archive, year. Link. Rights note.

## Research Tools

These tools are useful for edition discovery and rights verification. They are not collection targets by themselves.

- WorldCat. Library catalog for edition discovery. <https://www.worldcat.org/>.
- Internet Archive Texts. Scans and text collections for edition inspection. <https://archive.org/details/texts>.
- HathiTrust Digital Library. Library scans and rights metadata. <https://www.hathitrust.org/>.
- Project Gutenberg. Public-domain ebook library. <https://www.gutenberg.org/>.
- Standard Ebooks. Public-domain ebook editions. <https://standardebooks.org/>.
- Wikisource. Public-domain and freely licensed source texts. <https://en.wikisource.org/>.
