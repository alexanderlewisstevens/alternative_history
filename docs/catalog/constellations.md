# Constellations

Constellations are where the project starts to breathe.

Each constellation is a small, curated field of texts that should be read together. The point is not coverage. The point is relation: one text gives another a problem, a vocabulary, a wound, a method, a refusal, or an afterlife.

Use this page to design reading paths before drafting public essays or excerpt cards.

## How A Constellation Works

- Start with a strong question, not a category.
- Keep the group small enough for real reading.
- Name the relation between texts, not just their shared topic.
- Prefer tensions, reversals, inheritances, and transformations.
- Stay faithful to each text before making it serve a theme.

## Relationship Types

| Relation | Use |
| --- | --- |
| Tension | Two texts define a problem against each other. |
| Inheritance | A later text receives, reframes, or disciplines an earlier one. |
| Refusal | A text rejects a premise another text needs. |
| Translation | A text changes meaning through language, audience, or edition. |
| Afterlife | A text becomes powerful through commentary, teaching, or reuse. |

## Drafting Questions

- What is the live problem between these texts?
- Which passage should anchor the constellation?
- Which text should be read first, and why?
- Where does the reader need historical context before interpretation?
- What should the project refuse to flatten?
