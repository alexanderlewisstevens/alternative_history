# Historical Problems

Historical problem dossiers connect curated texts to moments where interpretation matters. They should not become broad event summaries.

Use a dossier when a historical moment helps readers test a critical vocabulary: archive, testimony, rhetoric, myth, translation, empire, memory, power, or historical judgment.
