# Texts

This catalog is a curated text register for the book. It is not a list of sites to scrape.

Add a source here only when there is a clear editorial reason to read it closely. Discovery can happen through libraries, catalogs, syllabi, anthologies, and archives, but selection happens text by text.

Move excerpts into `docs/catalog/excerpts.md` only after rights review.

After a text enters the register, place it into at least one [Constellation](constellations.md) or explain why it should stand alone for now.

## Selection Standard

Every candidate should answer three questions:

- Why does this text matter for theory, criticism, historiography, or historical imagination?
- What readerly habit does it unsettle?
- What edition, translation, or rights problem must be handled before public use?

## Edition-Finding Tools

Use catalogs and archives to locate specific editions, not to scrape broadly.

| Tool | Use |
| --- | --- |
| WorldCat and library catalogs | Identify editions, translators, publishers, and publication history. |
| Internet Archive, HathiTrust, and Google Books | Inspect scans for edition metadata and public-domain status. |
| Project Gutenberg, Standard Ebooks, and Wikisource | Locate public-domain reading copies when edition metadata is clear. |
| University presses and open-access book platforms | Locate scholarship with explicit licensing or citation metadata. |
