# Private Knowledge Base

This workspace is the project as a working notebook: part wiki, part reading journal, part Obsidian-style graph.

The public book can come later. For now, the useful thing is a private, searchable web of notes where texts, thinkers, passages, questions, and reading paths can build pressure on each other.

<div class="ah-private-banner">

  <span>Restricted extraction artifacts can inform local notes, but public promotion remains a separate rights-aware step.</span>
</div>

## How It Should Feel

The workspace should make it easy to move through the project in several directions:

- from a thinker to their texts;
- from a text to candidate passages;
- from a passage to a constellation;
- from a constellation to related thinkers and concepts;
- from an open question back into the extraction queue.

The page should not feel like a static encyclopedia entry. It should feel like a working surface.

## Workspace Rules

- Every note should have a type, status, source mode, and tags.
- Every serious note should link outward and show backlinks inward.
- Every copied passage needs source, page, edition, and rights status.
- Restricted material can remain private, but it should be marked private.
- The most important pages are the ones that connect texts, not the ones that merely summarize them.

## Navigation Model

Use three kinds of links:

| Link Type | Purpose | Example |
| --- | --- | --- |
| Wiki link | Human-friendly note identity | `[[Gorgias, Encomium of Helen]]` |
| Site link | Clickable local navigation | [Gorgias Text Note](gorgias-encomium-helen.md) |
| Source path | Audit trail into generated/private artifacts | `generated/authors/norton-theory-criticism/gorgias-of-leontini.md` |
