# Page Anatomy

A workspace page should be readable as prose, but useful as a node in a graph.

## Standard Header

<div class="ah-note-meta">
  <span><strong>Type:</strong> text note, thinker note, constellation note, passage note, concept note, or historical problem</span>
  <span><strong>Status:</strong> seed, drafting, reviewed, promoted, or blocked</span>
  <span><strong>Source mode:</strong> public, private, restricted, mixed, or original</span>
  <span><strong>Tags:</strong> rhetoric, poetics, archive, memory, empire, translation, commentary</span>
</div>

## Recommended Sections

| Section | Use |
| --- | --- |
| Working Claim | The current best reason this note matters. |
| Why It Matters | The interpretive problem the note opens. |
| Connected Notes | Direct links to texts, thinkers, concepts, passages, and constellations. |
| Passage Queue | Candidate source locations, with rights mode and review status. |
| Reading Notes | Original commentary, paraphrase, and questions. |
| Backlinks | Places where this note is already used. |
| Open Questions | Decisions that need another reading pass, source check, or issue. |

## Link Pattern

Use visible wiki-style labels when they help memory:

## Passage Card Pattern

<section class="ah-passage-card">
  <span class="ah-action-kicker">Passage Candidate</span>
  <h3>Short Descriptive Title</h3>
  <p><strong>Source location:</strong> Work, section, page, or generated page record.</p>
  <p><strong>Rights mode:</strong> private, public-domain candidate, open-license candidate, or rights-review needed.</p>
  <p><strong>Use:</strong> Explain why this passage matters before quoting it.</p>
  <p><strong>Commentary:</strong> Add original interpretive notes here. Keep source notes and bibliography separate.</p>
</section>
